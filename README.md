# تماريني | سجل الجيم

تطبيق عربي ثابت لتسجيل الجولات والأوزان وتقييم المجهود، مع مؤقت راحة عائم، ساعة للجلسة، تقويم، ستريك، وسجل تقدّم. لا يحتاج خادمًا أو اشتراكًا.

## النشر على GitHub Pages

1. أنشئ مستودعًا جديدًا على GitHub. ارفع **محتويات هذا المجلد** إلى فرع `main` مع الحفاظ على مجلد `.github/workflows` ومجلد `dist`. لا ترفع ملف ZIP كما هو داخل المستودع.
2. افتح المستودع ← **Settings → Pages → Build and deployment**، واختر **GitHub Actions** كمصدر النشر.
3. من **Actions** انتظر اكتمال `Publish Tamareeni to GitHub Pages`. يظهر الرابط في صفحة Pages أو نتيجة تشغيل المهمة.
4. أي تحديثات لاحقة على `main` تنشر النسخة الجديدة تلقائيًا.

الملفات الجاهزة للعرض داخل `dist/`. لا توجد مرحلة بناء أو مكتبات يجب تثبيتها. للعمل محليًا استخدم خادم ملفات ثابتة، مثل `python3 -m http.server 8080 --directory dist`، ثم افتح `http://localhost:8080`.

## نقل السجل من الرابط الحالي

بيانات المتصفح مرتبطة بعنوان الموقع. الانتقال من رابط Sites الحالي إلى GitHub Pages **لا ينقل الجلسات تلقائيًا**:

1. افتح الموقع الحالي من **نفس المتصفح والجهاز** الذي سجّلت عليه جلساتك.
2. افتح **الإعدادات → تنزيل نسخة JSON**، واحتفظ بالملف.
3. افتح رابط GitHub Pages الجديد ← **الإعدادات → استيراد نسخة**، واختر الملف. راجع السجل والتقويم بعد الاستيراد.

الاستيراد يستبدل البيانات الموجودة في المتصفح على الرابط الجديد؛ صدّر منها نسخة أولًا إن كنت قد استخدمته بالفعل.

## حفظ البيانات

- يحفظ التطبيق البيانات محليًا في `localStorage` ونسخة ثانية في `IndexedDB`. إذا تعطلت إحدى وسيلتي التخزين أو فقدت وحدها، يحاول استعادة النسخة الأخرى عند فتح الموقع.
- من **الإعدادات → اطلب حماية التخزين** يمكنك أن تطلب من المتصفح تقليل احتمال مسح بيانات الموقع تلقائيًا. قد يرفض المتصفح الطلب.
- التنزيل الدوري لنسخة JSON ضروري. حذف بيانات الموقع، التصفح الخفي، فقدان الجهاز أو تغيير المتصفح قد يمحو النسختين المحليتين. GitHub Pages يستضيف التطبيق فقط ولا يخزن حسابًا أو سجلًا في السحابة.
- إشعارات الراحة تحتاج إذن المتصفح وتُحدّث أثناء عمل الصفحة؛ قد يتأخر إشعار النهاية إذا عطل نظام الهاتف الصفحة في الخلفية.

للحفظ المتزامن بين الأجهزة واستعادة مضمونة بعد فقد الجهاز، يلزم لاحقًا حساب مستخدم وخدمة بيانات سحابية. لا تضع مفاتيح خاصة أو ملفات جلساتك الشخصية في مستودع GitHub العام.
